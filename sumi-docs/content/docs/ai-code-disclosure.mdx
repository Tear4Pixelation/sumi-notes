Here, I disclose where and how much AI code was used in Sumi.

<Callout type="warn" title="Entirely Vibecoded">
  All the code that came on top of [Write](https://www.styluslabs.com/) (not vibecoded) has been vibe coded, do with that what you will.

  The UI was hand-designed by me in [Penpot](https://penpot.app/), the open source Figma alternative, and then implemented by AI.

  All the new logic and algorithms were 100% AI.

  I made every decision myself from a developer's standpoint, but the AI wrote the code: I simply do not possess the time nor skill to do something of this magnitude in a language I don't know with a framework that is *custom built* by the original dev.
</Callout>

I want to be entirely clear that I am not *proud* of letting the LLM do all the heavy lifting for me. This is not one of those projects that advertises itself as "One person driving AI".
