All pens behave similarly, so we will cover them together.

Those would be: the pen, the highlighter and the ephemeral pen.

Their quick settings generally look like this:

![image](./assets/muir8wkg-image.png)

The permanent ones support [shape snapping and scribble to erase](./shape-snapping.mdx)

## Color presets

On the left, we have color presets. If you want to edit one, you click it again once it's active. To add one, click the plus button.

![image](./assets/muirjd9x-image.png)

You will get a menu with multiple colors to choose from. They have been matched to fit together using the theme you selected when creating the document, which is why:

<Callout type="warn" title="Custom Colors">
  I strongly advise against using custom colors. They will probably look out of place and can't be re-themed when the theme of the document changes
</Callout>

## Width presets

On the right of the separator, you have the pen width presets. They can be edited like the colors by pressing them once they are active.

![image](./assets/muirjt3g-image.png)

The popup will show you a preview of how that line width will look.

### Relative size

The relative size toggle you see at the top lets you choose a fraction of the current line height instead of an absolute value. This is helpful when your document has many different line heights *and* you want your pen to adapt to those. Paper patches are the typical case, since they can have a different line height than the page. It is on by default for the highlighter, so it always covers exactly one line.

## The highlighter

The highlighter is special in the sense that it goes behind all written strokes, to highlight something. It has one special option:

![image](./assets/muisuns6-image.png)

It keeps the highlighter centered between your lines, no need to worry about placement.

## Ephemeral pen

Like the normal pen, but it disappears after you let go.
