title: Select
---

The select tool allows you to select strokes and modify them.

![image](./assets/muiwweyp-image.png)

They always act in the context of the current page or paper patches.

It has four different settings on the left of the quick settings, and then [the switch back toggle](./index.mdx#switchback-toggle).

## Selector types

All except stroke select have the option to select everything that is only *touching* or *fully inside* the selected area.

![image](./assets/muiwrjpt-image.png)

### Lasso

You draw a shape which is your selection area.

### Box select

Select everything within a rectangle.

### Lined select

Select everything within the selected lines

![image](./assets/muiu0i0p-image.png)

### Stroke select

Everything that touches a stroke you drew is selected.

## Modifying strokes

Once you have made a selection, you will get this toolbar next to it

![image](./assets/muiwunvz-image.png)

It can cut, duplicate, copy, delete, add a link and change the color or width of your selected items.
