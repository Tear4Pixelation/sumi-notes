This is your main toolbar. It has all the tools you will use for editing.

It is split into two parts, the **tool selector** and the tool **quick settings**.

The quick settings are different for all tools and allow you to change their behaviour on the fly without having to dig through menus. It can be toggled by pressing the current tool.

## Tools

The currently available tools are (left to right):

- move
- [pen](./pens.mdx)
- [erase](./eraser.mdx)
- [highlighter](./pens.mdx#the-highlighter)
- [select](./select.mdx)
- [shape](./shape-tool.mdx)
- [ephemeral pen (active in the screenshot)](./pens.mdx#ephemeral-pen)
- insert space
- (undo)

## Switchback toggle

Many tools have this toggle:

![image](./assets/muh2t9en-image.png)

Which, when turned on, switches back to the previous tool after using the current one.
