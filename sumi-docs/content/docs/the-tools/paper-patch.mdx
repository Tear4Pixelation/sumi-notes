title: Paper Patch

![image](./assets/muj0f6ef-image.png)

The paper patch is an area with its own ruling, like lined, squared or dotted. You can think of it like sticking a lined sticky note onto a page. If you move it, the writing moves with it. All handwriting inside it follows its ruling, and the ruled tools also work based on it.

This can be really useful in scanned pdfs which either have strange, inconsistent or no ruling at all.

## Creation

Creating a paper patch is as easy as creating a rectangle. But after that things get different.

![image](./assets/muj0o7gf-image.png)

Here you can set up the paper patch to be exactly like you want it. The slider is the density of the ruling.

Dragging the corners now changes the shape instead of resizing. To scale it, use the white handle in the bottom right. You can also rotate.

![image](./assets/muj0q441-image.png)

Click the level button to make the ruling inside the patch aligned with the ruling of the paper.
