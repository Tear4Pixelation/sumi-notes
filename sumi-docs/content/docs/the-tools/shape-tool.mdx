The large quick settings make it look scary, I promise it isn't.

First let's take a look at the *right* of the quick settings.

There you have:

- color selection
- stroke width selection
- Add an arrow to the start or end of the line ![image](./assets/muizxnpq-image.png)
- Rounded corners

## Shapes

The first three are a simple line, a rectangle and an ellipse.

The last one, with the three lines, is called paper patch and deserves its own page.

### Polyline and Curve

These two allow you to add multiple points. Select the tool, set all the points you want and then click the last point again to finish.

While the **polyline** just goes straight between the points, the **curve** creates a smooth line between them.
