The insert space tool allows you to... insert space :)

It has two main modes. The left one is the free insert space tool, it moves everything on the page that is below the cursor down. Don't worry, the page expands at the bottom.

The other one is

## Ruled insert space

This feature can insert vertical space like the free tool but it will snap to the ruling of the paper.

**BUT** it can also reflow your text horizontally! This means that it can move words to the next line creating exactly the space for the one word you wanted to insert. And of course, there is also a toggle to make it reflow skipping a row if you want to leave one blank :)
